## 1. Eficiência de Desempenho e Latência (Performance Efficiency)

| Código SLO | Requisito Formal | Critério Técnico Mensurável | Métrica / SLA Alvo |
| :--- | :--- | :--- | :--- |
| **NFR-PERF-001** | Latência de Busca Georreferenciada | $95\%$ das requisições de leitura da API de busca com filtros combinados de acessibilidade e geodados devem responder em tempo ultra-baixo sob carga nominal. | $P_{95} \le 80\text{ ms}$, $P_{99} \le 150\text{ ms}$ (Carga: $1.000\text{ req/s}$). |

| :--- | :--- | :--- | :--- |
| **NFR-SEC-001**  | Criptografia em Trânsito | Todas as comunicações HTTP utilizam TLS 1.3 com HSTS forçado (`max-age=63072000`). | Qualificação A+ no teste Qualys SSL Labs. |
