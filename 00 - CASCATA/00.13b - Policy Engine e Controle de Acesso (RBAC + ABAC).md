## 1. Princípio Arquitetural: Zero Lógica de Autorização em Condicionais Dispersas

Para evitar a proliferação desgovernada de cláusulas `if` e garantir testabilidade unitária e auditoria matemática, o **Enlace** adota uma **camada de políticas explícita (Policy Engine)**.

Toda tentativa de ação do sistema é submetida a uma política formal que combina **RBAC (Role-Based Access Control)** com **ABAC (Attribute-Based Access Control)**:

```text
               REQUISIÇÃO (Sujeito, Ação, Recurso, Contexto)
                                     │
                                     ▼
                     ┌───────────────────────────────┐
                     │         POLICY ENGINE         │
                     │  (Motor de Políticas Centrais)│
                     └───────────────┬───────────────┘
                                     │
         ┌───────────────────────────┼───────────────────────────┐
         │                           │                           │
┌────────▼────────┐         ┌────────▼────────┐         ┌────────▼────────┐
│   AgePolicy     │         │  IdentityPolicy │         │VisibilityPolicy │
└─────────────────┘         └─────────────────┘         └─────────────────┘
┌─────────────────┐         ┌─────────────────┐         ┌─────────────────┐
│ContentAccessPlcy│         │ PurchasePolicy  │         │CommunicationPlcy│

```

## 2. Catálogo Formal de Políticas de Domínio

| Política | Responsabilidade / Invariante | Regra ABAC / RBAC Avaliada |
| :--- | :--- | :--- |
| **`AgePolicy`** | Impede acesso ou cadastro de indivíduos menores de 18 anos. | `Subject.calculatedAge >= 18` $\land$ `Subject.birthDateHash NOT IN Blacklist`. |
| **`IdentityPolicy`** | Autoriza publicação de anúncios comerciais. | `Subject.role == PROVIDER` $\land$ `Subject.verificationLevel >= 3` $\land$ `Subject.pixCpfMatch == true`. |
| **`VisibilityPolicy`** | Determina se um perfil pode ser indexado e exibido nas buscas. | `Resource.status == ACTIVE` $\land$ `Resource.isQuarantined == false` $\land$ `Resource.isBanned == false`. |
| **`ContentAccessPolicy`** | Autoriza a visualização ou streaming de um conteúdo multimídia. | `Resource.tier == PUBLIC` $\lor$ `Subject.id == Resource.ownerId` $\lor$ `EntitlementService.hasActiveEntitlement(Subject.id, Resource.id)`. |
| **`PurchasePolicy`** | Valida a elegibilidade para aquisição de mídias ou assinaturas. | `Subject.verificationLevel >= 2` $\land$ `Resource.sellerStatus == ACTIVE` $\land$ `Subject.isBlockedBy(Resource.sellerId) == false`. |
| **`CommunicationPolicy`**| Autoriza a emissão de cartão de solicitação e geração de deep link. | `Subject.id != Resource.providerId` $\land$ `MutualBlockService.isBlocked(Subject.id, Resource.providerId) == false` $\land$ `Subject.verificationLevel >= 2`. |
| **`AccessibilityPolicy`**| Valida a concessão e indexação de comodidades funcionais de acessibilidade. | `Resource.offeringCode IN RecognizedTaxonomy` $\land$ `Resource.isSelfAttested == true`. |
| **`TrustPolicy`** | Autoriza a submissão de avaliações públicas ou alertas confidenciais. | `Subject.hasConfirmedInteraction(Resource.targetId) == true` $\land$ `TimeSinceInteraction <= 7 days` $\land$ `ReviewNotYetSubmitted == true`. |

## 3. Matriz RBAC + ABAC Unificada

### Papéis (RBAC):
- `CLIENT`: Usuário consumidor sob pseudônimo.
- `PROVIDER`: Acompanhante profissional verificado.
- `MODERATOR`: Operador de revisão de quarentena.
- `SUPPORT`: Atendimento operacional de dúvidas sem acesso a dados civis.
- `ADMIN`: Administrador de infraestrutura e parâmetros da plataforma.
- `AUDITOR`: Acesso com leitura estrita a logs criptografados e atendimento judicial.

### Atributos Dinâmicos Avaliados (ABAC):
- `Subject`: ID, Papel, Nível de Verificação (0 a 4), Idade civil comprovada, Reputação/Score de Risco.
- `Resource`: ID, Proprietário, Tier de Acesso (Público, Paywall, Assinante), Status (Ativo, Quarentena, Banido).
- `Environment`: IP de conexão, País de origem, Indicador de desafio antibot (Turnstile), Carimbo de tempo.
