## 1. Mapeamento de Jornadas Principais

### Jornada 1: Descoberta e Contato com Anonimato (Cliente)

```
[ Acesso à Vitrine ] 
        ↓ (Sem necessidade de login inicial)
[ Filtro de Acessibilidade (ex: Libras) ] 
        ↓
[ Seleção de Acompanhante ] 
        ↓
[ Clique em "Conectar" ] 
        ↓
[ Criação Rápida de Sessão (+18) com Pseudônimo Automático: Cliente_XXXX ]
        ↓
[ Geração do Cartão Sanitizado ]
        ↓
[ Redirecionamento Direto via Deep Link wa.me (WhatsApp) ]
```

### Jornada 2: Compra de Mídia Privada com Split Instantâneo

```
[ Visualização de Mídia Borrada (Paywall) ]
        ↓
[ Clique em "Pagar R$ 35,00 via Pix" ]
        ↓
[ Apresentação do QR Code e Pix Copia e Cola EMVCo ]
        ↓
[ Liquidação pelo Cliente no App Bancário ]
        ↓
[ Webhook Pix: Repasse de 85% ao Payout Ledger + Desbloqueio Imediato ]
        ↓
[ Exibição em Alta Resolução com Marca d'Água Forense Injetada ]
```
