## 1. FSM 1: Ciclo de Vida do Perfil de Acompanhante

```mermaid
stateDiagram-v2
    [*] --> Rascunho : Cadastro inicial de contato
    Rascunho --> EmVerificacaoKYC : Envio de RG/CNH e biometria
    
    EmVerificacaoKYC --> RejeitadoMenor : Idade < 18 anos
    EmVerificacaoKYC --> RejeitadoDoc : Documento ilegível / divergente
    RejeitadoDoc --> EmVerificacaoKYC : Reenvio de documento
    
    EmVerificacaoKYC --> ValidandoTitularidadePix : Documento aprovado +18
    ValidandoTitularidadePix --> ChaveDivergente : CPF Pix diferente do documento
    ChaveDivergente --> ValidandoTitularidadePix : Atualização da chave Pix
    
    ValidandoTitularidadePix --> AtivoVerificado : Titularidade confirmada
    
    AtivoVerificado --> QuarentenaPreventiva : Limiar de >= 3 denúncias graves atingido
    QuarentenaPreventiva --> AtivoVerificado : Denúncias improcedentes na auditoria
    QuarentenaPreventiva --> BanidoDefinitivo : Ilícito confirmado
    
    AtivoVerificado --> InativoVoluntario : Prestador pausa anúncio
    InativoVoluntario --> AtivoVerificado : Prestador reativa anúncio
    
    RejeitadoMenor --> [*] : Registro em lista negra
    BanidoDefinitivo --> [*] : Bloqueio permanente de CPF/Hash
```

## 2. FSM 2: Ciclo de Vida da Ordem de Pagamento e Paywall

```mermaid
stateDiagram-v2
    [*] --> PendentePagamento : Cliente inicia checkout Pix
    
    PendentePagamento --> Expirada : Timeout de 15 minutos sem Pix
    PendentePagamento --> PagaLiquidada : Webhook confirma Pix recebido
    
    PagaLiquidada --> ProcessandoEsteganografia : Worker acionado para assinar mídia
    ProcessandoEsteganografia --> AcessoLiberado : Mídia assinada gerada no storage
    
    AcessoLiberado --> Reembolsada : Estorno por inconsistência técnica
    
    Expirada --> [*]
    Reembolsada --> [*]
    AcessoLiberado --> [*] : Acesso perpétuo à mídia pelo comprador
```

## 3. FSM 3: Ciclo de Vida da Assinatura de Destaque do Prestador

```mermaid
stateDiagram-v2
    [*] --> PadraoGratuito : Perfil aprovado sem plano ativo
    
    PadraoGratuito --> AssinaturaAtiva : Contratação de Plano (ex: Ouro/Diamante)
    
    AssinaturaAtiva --> Renovada : Cobrança recorrente autorizada
    Renovada --> AssinaturaAtiva
    
    AssinaturaAtiva --> AssinaturaExpirada : Fim do período sem renovação
    AssinaturaExpirada --> PadraoGratuito : Retorno suave ao ranking orgânico
    
    AssinaturaAtiva --> Cancelada : Cancelamento solicitado pelo prestador
    Cancelada --> PadraoGratuito : Fim do ciclo já pago
```
