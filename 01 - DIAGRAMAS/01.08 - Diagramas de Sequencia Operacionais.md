## 1. Sequência 1: Compra de Mídia Privada via Pix com Split Instantâneo

O diagrama a seguir descreve a interação ponta a ponta na aquisição de fotos ou vídeos exclusivos sob paywall:

```mermaid
sequenceDiagram
    autonumber
    actor Cliente as Cliente (Pseudônimo)
    participant Web as Frontend Next.js
    participant API as Backend Core (API)
    participant Gateway as Gateway de Pagamento
    participant Worker as Worker de Mídia
    participant Storage as Object Storage (S3)
    actor Prestador as Acompanhante

    Cliente->>Web: Clica em "Desbloquear Vídeo (R$ 50)"
    Web->>API: POST /api/v1/orders/checkout {mediaId}
    API->>API: Valida autorização e calcula split (85% / 15%)
    API->>Gateway: Cria Ordem Pix com Split (R$ 42,50 Prestador / R$ 7,50 Enlace)
    Gateway-->>API: Retorna QRCode e Chave Pix Copia-e-Cola
    API-->>Web: Exibe modal de pagamento com QRCode
    Cliente->>Gateway: Realiza pagamento Pix no aplicativo do banco

    Gateway->>API: Webhook: Pix Liquidado (Assinatura HMAC)
    API->>API: Valida webhook com idempotência e marca ordem como PAGA
    API->>Worker: Enfileira job: Aplicar esteganografia com ID do comprador
    Worker->>Storage: Busca vídeo original criptografado
    Worker->>Worker: Injeta marca d'água translúcida e hash esteganográfico
    Worker->>Storage: Grava versão assinada do comprador
    Worker-->>API: Job Concluído

    Gateway->>Prestador: Repassa R$ 42,50 instantaneamente na chave Pix
    API-->>Web: Evento SSE: Pagamento confirmado!
    Web->>API: GET /api/v1/media/stream/{mediaId}
    API-->>Web: Retorna URL HLS pré-assinada com expiração de 15 min
    Web-->>Cliente: Reproduz vídeo em player protegido
```

## 2. Sequência 2: Solicitação e Redirecionamento Direto para Canal Externo

O fluxo a seguir ilustra a baixa fricção e a ausência de burocracia na conexão para encontros presenciais:

```mermaid
sequenceDiagram
    autonumber
    actor Cliente as Cliente (Nível 2)
    participant Web as Frontend Next.js
    participant API as Backend Core (API)
    participant AppExt as WhatsApp / Canal Externo
    actor Prestador as Acompanhante

    Cliente->>Web: Acessa perfil e clica em "Solicitar Atendimento"
    Web-->>Cliente: Abre modal com formulário estruturado
    Cliente->>Web: Preenche (Data, Turno, Duração, Adaptações: Libras/Rampa)
    Cliente->>Web: Clica em "Enviar Solicitação Direta"
    Web->>API: POST /api/v1/requests/generate {providerId, details}
    API->>API: Registra solicitação para fins de avaliação futura
    API->>API: Monta mensagem padronizada com Pseudônimo e detalhes
    API->>API: Gera URL codificada do canal oficial do prestador (wa.me)
    API-->>Web: Retorna deep link seguro (https://wa.me/55...?text=...)
    Web->>AppExt: Dispara abertura do aplicativo externo no dispositivo
    AppExt-->>Prestador: Notifica acompanhante com a mensagem estruturada pronta
    Prestador->>Cliente: Responde diretamente no WhatsApp acordando os detalhes finais
```
